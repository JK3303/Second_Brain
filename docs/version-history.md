# Second Brain version history

## v1.0 — November 17, 2026

This is the first branded baseline of this Second Brain repository. The root
[VERSION](../VERSION) file contains its canonical repository version, `1.0`,
displayed as **v1.0**. The date records this branding baseline, not an earlier
GitHub Release or tag. This change is proposed for maintainer review and becomes
part of the default branch when the PR is merged.

The baseline covers the repository at revision
`dcfef6031024443cd8675025fd1e17f9b46c838d`: its project and creative-review
foundation, reusable handoff and source-change review methods, adopted
[workspace guidance](../workspace-standard.json), and merged explicit daily
contribution-delivery workflow. Availability of these materials does not prove
deployment, personal adoption of every capability, or successful external delivery.
Unmerged Art, Intent, Money, and GitHub workflow proposals are excluded.

This repository builds on [Open Brain](https://github.com/NateBJones-Projects/OB1)
by Nate B. Jones. The v1.0 designation belongs to this repository, not upstream
Open Brain or its individual extensions. For the original systems and learning
resources, see [Nate's newsletter](https://substack.com/@natesnewsletter) and
[Nate's site](https://natebjones.com).

Repository versions advance independently of component, runtime, and
workspace-standard versions. This designation preserves their existing values,
provenance, and approval boundaries. It introduces no new runtime behavior,
capture, reporting requirement, permission, or next-increment objectives.
