# Shared workspace standard 0.2.0 proposal

Status: proposed; no personal adoption or runtime activation recorded.

## Purpose

Use common delivery, privacy, exchange, and continuity guidance while preserving this repository's existing project boundaries, creative process, decision authority, and human acceptance of reusable lessons.

## Shared source

The [standard](personal-workspace-standard.md) retains the shared 0.2.0 behavior with generalized public attribution; its bytes intentionally differ from the upstream copy. The [exchange contract](personal-workspace-exchange-contract.md) is an exact reviewed shared copy. [The version record](../workspace-standard.json) pins the actual and upstream digests and landed source revision. Runtime versions are separate; this proposal installs no runtime.

## Local authority and adaptations

Keep [repository instructions](../AGENTS.md), [project membranes](second-brain/project-membranes.md), [decision states](second-brain/decision-states.md), [creative calibration](second-brain/calibration-loop.md), and [lesson promotion](second-brain/lesson-promotion.md) authoritative within their existing scope. Resolve a concrete conflict through explicit review rather than silently overriding a local control.

Continuity can use existing source-linked resumption and decision records. No mandatory cadence, record for every conversation, or automatic memory promotion is introduced.

## Local interpretation

- Preserve the existing creative calibration loop for structured exercises; it is not a required process for every routine task.
- Preserve required Linear updates for work already tied to an issue. No new tracker or universal logging obligation is introduced.
- Keep existing decision-state names. For delivery claims under this guidance, additionally verify the intended destination and distinguish a local save, upload, deployment, and public publication.
- Accepted lessons remain governed by explicit human acceptance and applicability limits. This proposal does not move existing memory, admit transcripts, or authorize new retention.
- Preserve repository-specific worktree and publication requirements, including Open Brain attribution. Shared guidance supplies no branch, commit, push, or namespace authorization.

This repository builds on [Nate B. Jones's Open Brain](https://github.com/NateBJones-Projects/OB1). Further practical systems are available through [Nate's writing](https://substack.com/@natesnewsletter) and [website](https://natebjones.com).

## Authority limits

This proposal grants no capture, runtime activation, automatic synchronization, private-data intake, client contact, publication, spending, account changes, or sharing permissions. Existing task-specific permissions remain necessary.
