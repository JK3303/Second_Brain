## Automation and communication

After adoption, a scheduled agent may perform the same collection/consolidation
and compile one current draft per business day. Use the host's supported scheduler
only after Jon chooses the time, timezone and permitted sources. Merging this
PR does not install a scheduler or grant connector access.

Preparation, review, sending and confirmed provider delivery are separate states.
The compiler has no send operation. Never send or claim a daily email was sent
without explicit authority for the sender, exact team recipients and either that
message or a bounded standing-send policy. Reuse existing explicit permission;
do not ask every day if it already covers the action. Check provider history for
the day's message before any authorized retry; an unknown send result requires
reconciliation, not another send. Preserve sent correspondence through the
existing authorized record route. Do not change mailing-list membership.
