# Preserve meaning and identity

Inspect the accepted source before changing it. Identify protected words, numbers,
qualifications, citations, product features, artwork, and their relationships. Compare
the returned candidate with that source. Matching colors or atmosphere does not
preserve an actual frame, emblem, or composition. Report an unavailable reference;
never present an approximation as its recovery.

Source-bound text must retain claims and uncertainty. Compare both text and rendered
placement; an exact-copy prompt is not proof. Fix drift within scope, including all
affected reading modes. Missing event dates or unknown product dimensions remain
missing facts; do not invent them to make a layout appear finished.

For exact typography, use real typesetting with the actual available, licensed font
when permitted by the governing tool rules. Verify renderer loading and inspect
glyphs, case, weight, and spacing. A named font in a generation prompt or computed
website CSS does not establish an exact rendered match. Separate generated artwork
from deterministic text when appropriate; do not bypass mandatory image-edit tools.

For actual product views, preserve pattern, color, proportions, edges, and visible
wear or damage. Compare originals and edits side by side, including detail crops
where necessary. Reject invented features and repaired defects. An AI disclosure
does not cure a materially inaccurate product photograph. If fidelity remains
uncertain, retain the original as the factual view. Verify real alpha for transparency;
a painted checkerboard is not transparency. Maintain source/output mapping in batches.
