# Project Manifest Template

Copy this file into your project directory and fill in the fields.

```
Project:
Owner:
Purpose:
State:
Privacy level: public / internal / restricted
Allowed sources:
Prohibited sources:
What may become reusable memory:
What must remain project-local:
External-action rule:
Review owner:
Current entry point:
Next review:
```

## Field guide

- **Project** — name of the project
- **Owner** — who holds creative and decision authority
- **Purpose** — one sentence on what the project is for
- **State** — current phase (use the vocabulary from `docs/second-brain/decision-states.md`)
- **Privacy level** — public (anyone can see), internal (repo collaborators only), restricted (owner only)
- **Allowed sources** — what information the project may use (public materials, supplied materials, self-created, etc.)
- **Prohibited sources** — what the project must not use (private data, uncleared images, client material, etc.)
- **What may become reusable memory** — lessons or patterns that could be promoted to global scope via `docs/second-brain/lesson-promotion.md`
- **What must remain project-local** — facts, decisions, client details, and material that must not leak outside the project
- **External-action rule** — what the project cannot authorize (publishing, spending, deployment, client contact, etc.)
- **Review owner** — who reviews and approves state transitions
- **Current entry point** — the file to read first
- **Next review** — what happens next and who decides
