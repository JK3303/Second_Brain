# Decision Receipt Template

Copy this template for each significant decision or state transition.

```
Decision ID:
Project:
Status:
Source:
Decision owner:
Evidence:
Alternatives considered:
Uncertainty:
Authority or approval:
Reversible: yes / no
Next action:
```

## Usage

- One receipt per decision or state transition.
- Use the state vocabulary from `docs/second-brain/decision-states.md`.
- Do not infer approval from a polished artifact, previous practice, silence, or urgency.
- A recommendation is not approval.
- Include what remains uncertain, not just what supports the decision.
