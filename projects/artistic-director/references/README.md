# References

Curated reference materials for the Artistic Director studio.

## Guidelines

When adding a reference, record:

- **Why it matters** — not just a link, but what principle or technique it illustrates.
- **Rights status** — public domain, Creative Commons, fair use, licensed, or unknown.
- **What generic principle may be learned** from it.
- **What must not be copied** from it.
- **Whether the reference is safe to reuse** in studio work.

Private or licensed source material must not be committed to this public repository. Record the lesson, not the asset.

See `reference-log.md` for the running list and `rights-and-attribution.md` for rights tracking.
