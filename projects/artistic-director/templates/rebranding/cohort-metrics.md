## Recording rules

1. Record what was actually observed. If a metric was not measured, write **not measured** — never estimate.
2. If a workflow step did not run, write **not run — gated at Step _** and name the gate.
3. Time is wall-clock human time unless stated otherwise.
4. A "correction" is a change the AD required, not a change the AI made on its own initiative.
