# Prompt Patterns

Reusable prompt structures for common creative operations in the studio.

## Exploration prompt

> Given [context], generate [N] materially different approaches to [objective]. For each approach, explain the creative reasoning and identify what makes it distinct from the others.

## Critique prompt

> Review [work] against the critique rubric. Focus on [specific dimensions]. Identify strengths, weaknesses, and one specific improvement for each weakness.

## Revision prompt

> Revise [work] based on this feedback: [critique]. Explain what changed and why. Do not silently drop any element of the feedback.

## Lesson extraction prompt

> From this critique-revision cycle, propose one reusable rule. State the rule, the evidence from this cycle, and the conditions under which it should or should not apply.

## Comparison prompt

> Compare [option A] and [option B] across [dimensions]. Do not declare a winner. Present the tradeoffs so the human can decide.

---

_Add new patterns as the studio develops. Each pattern should emerge from actual use, not be invented speculatively._
