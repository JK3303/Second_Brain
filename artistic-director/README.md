# Artistic Director Studio

A creative collaboration studio within Second_Brain — a personal AI second-brain system for projects, memories, skills, and experiments.

## What this is

This directory is one project inside the Second_Brain repository. It provides role definition, AI working methods, creative memory, and a practice space for the Artistic Director. The studio operates independently while sharing the repository's infrastructure and history.

The overlay is not required to stay in exact sync with Anyang Intelligence. The human owns the creative evolution of the studio.

## Governance

- Chief Executive observation is read-only and does not create task authority.
- Job-specific material (client work, campaign assets) belongs in a later, separately bounded project area, not here.
- This Phase 1 layer is job-neutral. It contains no client facts, customer records, private evidence, campaign requirements, or assumed brand direction.

## Where to find things

| Area | Purpose |
|------|---------|
| `charter/` | Role definition, working agreement, and authority boundaries |
| `ai/` | System instructions, collaboration loop, critique rubric, calibration exercises |
| `memory/` | Role principles, creative vocabulary, accepted and rejected lessons, open questions |
| `references/` | Curated reference materials with rights and attribution tracking |
| `practice/` | Creative laboratory: briefs, concepts, critiques, experiments |
| `decisions/` | Creative decision log, holds, rejections, and review receipts |
| `evaluations/` | Human reviews, AI self-reviews, and cohort-level assessments |
| `handoff/` | Current state, successor guide, and exit record |

## Phase 1 status

Phase 1 focuses on studio formation: establishing safety, orientation, and the first calibration exercise. See `handoff/current-state.md` for progress.
